Lecture 15 — Want / Wants

Expressing Needs, Wants & Questions
WantWantsSingular / PluralInfinitiveDo / DoesWH Questions
Lecture Goal: “चाहिए” वाले sentences को want / wants से बनाना, singular–plural rule समझना, infinitive जोड़ना, negative और interrogative बनाना.

1. What Does “Want” Mean?

Want का basic meaning है चाहना / चाहिए होना. जब हमें किसी चीज़ की need या desire बतानी हो, तब want use करते हैं.

Subject + Want + Object
HindiEnglish
मुझे पानी चाहिए।I want water.
मुझे तुम्हारी मदद चाहिए।I want your help.
मुझे तुम्हारी किताबें चाहिए।I want your books.
मुझे तुम्हारा फोन नंबर चाहिए।I want your phone number.
मुझे ज्ञान चाहिए।I want knowledge.

2. Want vs Wants

Want और wants का basic meaning same है. फर्क subject के हिसाब से होता है.

SubjectUse
I, We, You, Theywant
He, She, It, Name / Singularwants
Shortcut: I/We/You/They → want | He/She/It/Name → wants

3. Pronunciation

want का pronunciation सही रखना जरूरी है. Lecture में pronunciation पर विशेष ध्यान देने को कहा गया और word को “वांट” के करीब बोलने का अभ्यास कराया गया.

4. Different Subjects — Practice

HindiEnglish
राजू को नाश्ता चाहिए।Raju wants breakfast.
हमें तुम्हारी मदद चाहिए।We want your help.
उन्हें फल चाहिए।They want fruits.
उसे कुछ किताबें चाहिए।He wants some books.
तुम्हें मेरे कपड़े चाहिए।You want my clothes.
Extra word: कुछ = some, ज्यादा = much (context-dependent).

5. Advanced Use — Want + To + V1

जब किसी चीज़ के साथ यह भी बताना हो कि वह किस काम के लिए चाहिए, तो infinitive structure useful है.

Subject + Want/Wants + Object + To + Verb (First Form)
HindiEnglish
मुझे पीने के लिए जूस चाहिए।I want juice to drink.
उसे रहने के लिए मकान चाहिए।He wants a house to live in.
मुकेश को खाने के लिए खाना चाहिए।Mukesh wants food to eat.
Build it step-by-step:
“मुझे पीने के लिए जूस चाहिए” → Main idea: I want juice. → Purpose: to drink → I want juice to drink.
For + -ing भी कुछ contexts में possible है, लेकिन lecture में to + V1 को preferred form बताया गया.

6. More Want / Wants Sentences

HindiEnglish
राहुल को नया बैग चाहिए।Rahul wants a new bag.
मुझे एक मौका चाहिए।I want a chance.
उसे अच्छी नौकरी चाहिए।He wants a good job.
हमें एक बड़ा कमरा चाहिए।We want a big room.
बच्चों को चॉकलेट चाहिए।Children want chocolate.

7. Negative Sentences

Want एक main verb है, इसलिए negative में do / does + not का use किया जाता है.

Subject + Do/Does + Not + Want + Object
Subject TypeNegative
I / We / You / They / Pluraldo not / don't want
He / She / It / Name / Singulardoes not / doesn't want
Important: doesn't want के बाद wants नहीं आएगा. Correct: He doesn't want...

Examples

HindiEnglish
मुझे उसकी कार नहीं चाहिए।I don't want his car.
हमें उनके पैसे नहीं चाहिए।We don't want their money.
उन्हें ज्ञान नहीं चाहिए।They don't want knowledge.
मुझे मदद नहीं चाहिए।I don't want help.
तुम्हें नया फोन नहीं चाहिए।You don't want a new phone.
राम को छुट्टी नहीं चाहिए।Ram does not want leave.
नीता को किताबें नहीं चाहिए।Neeta doesn't want books.

8. Do vs Does — Revision

DoDoes
IHe
WeShe

Memory Rule: Singular → does | I/you/we/they/plural → do.

9. Interrogative Sentences

Question बनाने के लिए helping verb do / does को शुरुआत में लाते हैं.

Do/Does + Subject + Want + Object?
HindiEnglish
क्या बच्चों को चॉकलेट चाहिए?Do children want chocolate?
क्या शिक्षक को सम्मान चाहिए?Does the teacher want respect?
क्या माता-पिता को शांति चाहिए?Do parents want peace?
क्या तुम्हारे दोस्त को छुट्टी चाहिए?Does your friend want leave?
क्या राम को नया मोबाइल चाहिए?Does Ram want a new mobile?
Question rule: Do/Does आगे आते ही main verb want रहेगा, wants नहीं.

10. Interrogative Negative

Do/Does + Subject + Not + Want + Object?
HindiEnglish
क्या छात्र को सफलता नहीं चाहिए?Does the student not want success?
क्या माता-पिता को आराम नहीं चाहिए?Do parents not want rest?
क्या तुम्हें मोबाइल नहीं चाहिए?Do you not want a mobile?
क्या उस मरीज को दवा नहीं चाहिए?Does that patient not want medicine?
क्या ग्राहक को अच्छी service नहीं चाहिए?Does the customer not want good service?

11. WH Questions

जब प्रश्न में क्या, क्यों, कौन-सी, किसकी आदि आएं, तो WH word सबसे पहले आता है.

WH + Do/Does + Subject + Want + Object?
HindiEnglish
तुम्हें क्या चाहिए?What do you want?
तुम्हें यह क्यों चाहिए?Why do you want this?
राम को कौन-सी किताब चाहिए?Which book does Ram want?
उसे खिलौने क्यों चाहिए?Why does he want toys?
आपको मेरा मोबाइल क्यों चाहिए?Why do you want my mobile?
Core idea: WH word → Do/Does → Subject → Want → Object.

14. Sentence-Building Strategy

Step 1: Subject पहचानो.
Step 2: “चाहिए” देखकर want/wants चुनो.
Step 3: Object जोड़ो.
Step 4: जरूरत हो तो to + V1 से purpose जोड़ो.
Step 5: Negative में do/does + not.
Step 6: Question में do/does आगे.
Step 7: WH question में WH word सबसे आगे.
